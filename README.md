# miniguia-pcm-com-ia
"Miniguia de Planejamento e Controle de Manutenção (PCM) voltado para iniciantes, com o auxílio de ferramentas de Inteligência Artificial. Apresenta conceitos fundamentais, importância, atividades, glossário e uma coleção de prompts prontos para consultas rápidas, facilitando o aprendizado e a prática de quem está começando."
